# Student Management System (MVC Architecture)
This is a simple student management system built using the MVC (Model-View-Controller) architecture. It helps track students, courses, and enrollments.
**Features**
CRUD operations for students, courses, and enrollments
Relationship between tables (students can enroll in multiple courses)
Clean MVC architecture
User-friendly interface

**Database Structure**
students: Stores student information (id, name, nim, phone, join_date)
courses: Stores course information (id, course_code, course_name, credits, description)
enrollments: Tracks which students are enrolled in which courses (id, student_id, course_id, enrollment_date, grade)

**Setup Instructions**
Prerequisites:
PHP 7.0 or higher
MySQL/MariaDB server
Web server (Apache, Nginx, etc.)
